# `Lambda`-разгон

::left::

`Lambda` - анонимная функция


- Одно выражение, значение возвращается сразу
- Обычно используется как аргумент в высокоуровневых функциях

::right::

````md magic-move
```python
# -*- coding: utf-8 -*-
```

```python
def manhattan_dist(point: list[float, float]) -> float:
  return abs(point[0]) + abs(point[1])

manhattan_dist(3, -4) # -> 7
```

```python
manhattan_dist = lambda p: abs(p[0]) + abs(p[1])

manhattan_dist(3, -4) # -> 7
```

```python
(lambda p: abs(p[0]) + abs(p[1]))((3, -4))  # -> 7
```
````

# `Lambda`-разгон / `map`

::left::

- `map(f, *iterable)`
- Применяет `f` к *каждому* элементу `iterable`
- Возвращает `iterable`

::right::

````md magic-move
```python
manhattan_dist = lambda p: abs(p[0]) + abs(p[1])
```

```python
manhattan_dist = lambda p: abs(p[0]) + abs(p[1])

points = [(1, 2), (3, 4), ..., (8, 9)]
```

```python
manhattan_dist = lambda p: abs(p[0]) + abs(p[1])

points = [(1, 2), (3, 4), ..., (8, 9)]

dist = map(manhattan_dist, points)
# [3, 7, ..., 17]
```

```python
points = [(1, 2), (3, 4), ..., (8, 9)]

dist = map(lambda p: abs(p[0]) + abs(p[1]), points)
# [3, 7, ..., 17]
```

```python
x_coords = [0, 1, 2, 3]
y_coords = [5, 4, 3, 2]

points = map(lambda x, y: (x, y), x_coords, y_coords)
# [(0, 5), (1, 4), (2, 3), (3, 2)]
```

```python
points1 = [(0, 0), (1, 1), (2, 2)]
points2 = [(3, 4), (5, 1), (0, 7), (9, 9)]

dist_sq = map(lambda p1, p2: (p1[0]-p2[0])**2 + (p1[1]-p2[1])**2,
                   points1, points2)
```
````

# `Lambda`-разгон / `arg(..., key=f)`

::left::

- аналогично `map` применяет `f` к каждому элементу
- в отличие от `map`, `key` просто позволяет понять, что сравнивать

::right::

````md magic-move
```python
points = [(1,15), (10, 2), (14, 3)]

min(points) # :(
# -> (1, 15)
```

```python
points = [(1,15), (10, 2), (14, 3)]
min(points, key=lambda p: abs(p[0]) + abs(p[1]))
# -> (10, 2)
```
````

<!--
Замечательная штука key есть для сортировок. Она позволяет не писать кучу кода для того, чтобы понять, что сравнивать. Например, у нас есть список точек, и мы хотим найти точку, которая ближе всего к началу координат. Сравнивать точки напрямую бессмысленно, [click] а вот сравнивать например их расстояние до начала координат - уже имеет смысл. И вот тут на помощь приходит key.

-->
